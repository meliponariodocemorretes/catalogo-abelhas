# Catálogo de abelhas Doce Morretes

Onze fichas de abelhas sem ferrão de interesse para a Mata Atlântica da Serra do Mar e o litoral paranaense.

Site: https://meliponariodocemorretes.github.io/catalogo-abelhas/

Página da mandaçaia: https://meliponariodocemorretes.github.io/catalogo-abelhas/mandacaia-mqq.html

## Conteúdo

- Jataí, mandaçaia MQQ, guaraipo, bugia, borá, tubuna, mandaguari, mombucão e mirins emerina, droryana e guaçu.
- Mandaçaia com as fotografias fornecidas; demais fichas com espaços reservados para fotos futuras.
- Referências científicas e créditos por fotografia em `creditos.html`.
- Marca principal e ícone mínimo Doce Morretes. O selo institucional foi excluído conforme orientação da marca.
- Paleta `#1A3322`, `#D4A373`, `#FAEDCD`; títulos em Georgia, textos em Segoe UI.

## Publicação

HTML, CSS e JavaScript estáticos, sem dependências de instalação. GitHub Pages deve usar `main` e `/(root)`. O arquivo `.nojekyll` preserva a publicação estática.

Para visualizar localmente, abra `index.html` ou sirva a pasta com um servidor HTTP. A busca e a ampliação das fotos funcionam sem serviços externos.
